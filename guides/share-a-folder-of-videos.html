How to share a whole folder of saved videos with one link

By Devon, maker of Bulletn

To share a whole folder of saved videos, put them in one Bulletn folder and choose Share Folder. You get one link. The person you send it to opens it in a browser and sees every save in the folder. They do not need Bulletn to view it.

The trouble with sending videos one by one

Say you found twelve videos for a trip. You could send twelve messages. Then the links get buried in the chat, replies land in between, and nobody can find the good one when it counts.

It gets worse when the videos come from different apps. Some are TikToks, some are reels and some are on YouTube. One app's saved list cannot hold them all.

Other ways to share a group of links

  • A YouTube playlist. Good when every video is on YouTube. It only holds YouTube videos.
  • A shared note. Works for any link. You have to paste and label each one, and a long list of raw links is hard to read.
  • A group chat. Easy to start and hard to search later.

These are fine for a few links. A folder link is better when you have a real collection to pass on.

How to share a folder with Bulletn

1. Save the videos

In TikTok, Instagram, YouTube, Facebook or any app with a Share button, tap Share, open the iPhone share sheet and pick Bulletn. Some apps label the share sheet More or Share to.

2. Get them into one folder

You can pick the folder yourself as you save. Or let AI sorting place each save in the folder that fits. If it is not sure, the save waits in Unsorted with one suggested folder, and one tap moves it.

Already have them in different folders? Use Select mode to move several saves at once.

3. Look it over

Open the folder and read the list like your friend will. Remove anything you would not want to send. Give the folder a name that makes sense to someone else. "Lisbon food" is better than "Stuff 2."

4. Share the link

Open the menu on the folder and choose Share Folder. Send the link however you like.

What the other person sees

The link opens a web page that lists the folder. Each save is there, whichever app it came from. They do not have to make an account.

If they have Bulletn installed, they can add the folder in one tap.

Where the folder lives

The folder travels inside the link. Nothing is uploaded. That means a few things:

  • It is a snapshot. The link holds the folder as it was when you shared it. If you add more saves, share it again.
  • Anyone with the link can open it. Treat it like any link you send. Share it with people you want to see it.
  • Post rules still apply. If a video is from a private account or gets deleted, your friend may not be able to watch it.

Good folders to share

  • Trip ideas. Send one link to everyone going, so the planning starts from the same list.
  • Holiday recipes. Share the sides and desserts with whoever is cooking.
  • Workouts. Give a friend the routine you follow.
  • Kid activities. Pass a rainy day list to a grandparent or sitter.
  • House projects. Show a partner or contractor the look you want.
  • Gift ideas. Save them during the year and send the list when someone asks.

Keep the folder useful for you too

The folder you share is still your folder. Add a photo cover so it is easy to spot. Add notes to remember why you kept each video. Set a reminder on the one you want to try first. Search by title, note or folder to find any save later.
